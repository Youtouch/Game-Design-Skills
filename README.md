# Game Design Skills

Agent skills for a game designer and level designer AI companion.

## Scope

- **Design only.** Skills help reason about, document, and critique game and level design. They do not cover engine implementation, code, or asset production.
- Covers general game design and level design, including Rational Game Design and Rational Level Design.

## Layout

- [Design critique](skills/design-critique/SKILL.md): research-informed critique for tracing rules and information, examining learning and participation, checking chance claims, and synthesizing design tradeoffs. Includes original lessons and source boundaries; effectiveness is not yet empirically validated.

- `skills/<name>/SKILL.md`: one folder per skill.
- `AGENTS.md`: conventions for agents contributing to this repo.
- [Multi-lens design analysis](docs/multi-lens-design-analysis.md): accepted reasoning direction and evaluation requirements for the design skillset.
