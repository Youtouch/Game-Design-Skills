# Interpret the outcome that was measured

Use this reference when a comparison is being promoted into a claim about learning, engagement, or enjoyment. A useful production decision does not require claiming more than the evidence establishes.

Before interpreting a result, record:

- Outcome and unit: levels completed, active seconds, return visits, errors, participant accounts, or a demonstrated fresh application.
- Assignment and identity: what was randomized, who or what counts as one participant, repeat exposure, exclusions, and missing observations.
- Comparison: which aspects changed together, observation window, group differences, and assistance conditions.
- Uncertainty: denominators, distributions or summaries available, intervals when justified, and null or adverse outcomes as well as favorable ones.

Randomization can strengthen an inference about an assigned package within its sampled conditions. It does not isolate each feature inside that package or establish the cause of differences between self-selected game populations. Nonsignificance alone does not prove equivalence. Different rank distributions can coexist with equal medians.

## Controlled-study precedent

Andersen et al., *The Impact of Tutorials on Games of Varying Complexity*, CHI 2012 ([author-hosted paper](https://grail.cs.washington.edu/projects/game-abtesting/chi2012/chi2012.pdf); Table 3, PDF p. 8; limitations/discussion, pp. 9–10), compared randomized tutorial packages within three games. Sol's research read the ten-page paper and checked the result tables. It found positive, null, and adverse measured outcomes: contextual guidance improved some Foldit progress/time summaries, while other game/condition comparisons did not improve those measures or had lower return rates.

These are behavioral outcomes, not direct measurements of mastery, enjoyment, or access. Game complexity was not randomized across games, and concept order was not the experimental comparison. The paper reports no effect confidence intervals and contains count/direction discrepancies between some tables and prose; avoid precise pooled estimates or universal forecasts from it. In particular, Table 3's aggregate Hello Worlds help comparison shows lower return, despite prose describing an increase. Use the bounded within-game evidence without importing a universal tutorial order, effect size, or sample requirement.

## Synthetic application

A contextual map hint increases first-room completion. That could mean better control discovery, successful copying of a revealed answer, or other changes bundled with the hint. Record which actions players used and what was shown. If the decision concerns transfer, observe a new opportunity to use the principle; if it concerns enjoyment, seek appropriate participant evidence. A clue description, a solution hint, and an input accommodation are different interventions. Preserve or change them according to the actual decision rather than treating completion as the final answer to every question.
